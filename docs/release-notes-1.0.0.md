首个公开版本。Windows 10 / 11 x64 单文件程序，无需安装。

### 包含

- 桌面挂件：时间、日期、农历、天气、体感温度、湿度与风速
- 背景透明度 25%–100% 可调（设置滑块或 `Ctrl + 滚轮`）
- 便签：自定义类别（名称、颜色、默认类型），文本与待办两种形态
- 便签置顶、自动保存、位置/大小记忆、重启恢复
- 深色 / 浅色主题、6 种强调色、始终置顶、开机自启、托盘、单实例
- 天气数据来自 Open-Meteo；便签与配置保存在本机 `%APPDATA%\LuminaDesk`

### 说明

程序未做商业代码签名，首次运行 SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。
