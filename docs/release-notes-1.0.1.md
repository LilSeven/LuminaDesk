# Lumina Desk 1.0.1

## 修复

- 秒数与时、分改为共享同一条文字基线，不再像上标一样浮在右上角。
- 时间区域改用自绘文本，避免全局 QSS 字号覆盖导致的大小与对齐漂移；12 小时制的“上午/下午”也随基线对齐。

## 下载

- Windows 10/11 x64 单文件版：[LuminaDesk.exe](https://github.com/LilSeven/LuminaDesk/releases/download/v1.0.1/LuminaDesk.exe)

数据仍保存在 `%APPDATA%\LuminaDesk`，覆盖旧版 exe 即可，配置与便签不受影响。
