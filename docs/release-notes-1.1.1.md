# Lumina Desk 1.1.1

## 修复

- **点击便签左上角的类别标签没有反应**：现在会正常弹出下拉框，可在“备忘录 / 待办列表 / 灵感 / 收集箱”等类别间直接切换。
- 下拉框中会标出当前类别，选中后立即生效并保存。

## 改进

- 切换到默认内容类型不同的类别时（例如从“备忘录”切到“待办列表”），会先确认再转换：
  - 文本 → 待办：按非空行拆分，段落格式不保留；
  - 待办 → 文本：按行合并，勾选状态不保留。
- 取消确认时，类别和内容都保持原样。

## 升级

直接下载并替换旧的 `LuminaDesk.exe` 即可，配置、便签和自定义背景都会保留。

下载：[LuminaDesk.exe](https://github.com/LilSeven/LuminaDesk/releases/download/v1.1.1/LuminaDesk.exe)
