# Lumina Desk 1.1.2

## 修复

- **天气长时间不刷新，一直停在「缓存 · 更新于 xx:xx」**：天气和城市搜索现在直连 Open-Meteo，不再经过系统代理。此前如果系统代理（本地 VPN、Clash 类客户端）把请求挂住，应用会一直等下去，看起来就像数据不再更新。
- 新增 20 秒硬超时：请求超时后立即放弃、复位状态，后续自动刷新不会再被卡住的请求静默挡住。
- 刷新失败时状态栏显示「刷新失败 · 上次 xx:xx」，不再默默沿用旧时间；失败后 60 秒自动重试一次。

## 说明

- 自动刷新间隔、缓存回退逻辑都没有变，仍是设置里的 5–60 分钟。
- 直连只影响 Open-Meteo 的两个接口（天气、地理编码），其它行为不变。

## 升级

直接下载并替换旧的 `LuminaDesk.exe` 即可，配置、便签和自定义背景都会保留。

下载：[LuminaDesk.exe](https://github.com/LilSeven/LuminaDesk/releases/download/v1.1.2/LuminaDesk.exe)
